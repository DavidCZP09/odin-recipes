# Swift Playgrounds version

A SwiftUI rewrite of `tic-tac-toe.html`, for testing on iPad in the Swift Playgrounds app.

## How to use

1. Open Swift Playgrounds on your iPad.
2. Create Playground -> App template.
3. Open `ContentView.swift` in the new project.
4. Replace its contents with `ContentView.swift` from this folder.
5. Tap Run.
